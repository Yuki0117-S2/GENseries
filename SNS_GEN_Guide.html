⚙️ 내부 동작 규칙

changeMode() 시 흐름

1. captureArea.className = '' — 클래스 리셋

2. captureArea.classList.remove('pan-target') — pan-target 제거

3. captureArea.style.height = '' — 인라인 높이 비움

4. 새 모드 클래스 적용

5. updateImageSettings() 호출 → 비율 재계산

6. updateUI(), updateUiZoom(), 모바일이면 applyMobileAutoZoom()

updateImageSettings() 시 흐름

1. getActivePanTarget() 으로 현재 타겟 결정

· yt_std → ytContainer

· x → xContainer

· ig_post → igPanBox

· ph → phContainer

· 그 외 (카메라 포함) → captureArea

2. backgroundSize 설정 (cover or N%)

3. 잔류 인라인 정리 — captureArea + target의 height, aspectRatio 비움

4. isAutoRatio 분기로 비율 적용

모바일 자동 fit 로직

fitPreviewToWrapper() 함수

· padding: 48 (모바일) / 60 (PC)

· bottomSafeMargin: 60 (모바일 하단바 + safe-area)

· safety: 0.95 (여유분)

· Math.max(0.05, ...) clamp — 정밀 조정

· scheduleAutoFit(delay=320ms) — media-box transition 이후 측정

슬라이더 정밀도

· uiZoomSlider: min=0.05, step=0.01

· numUiZoom, miniNumUiZoom: 동일

🧪 최근 패치 노트

📷 카메라 selMediaRatio 누수 버그 해결

이전엔 다른 모드에서 9:16으로 설정 후 카메라 진입 시 잔류로 박스 깨졌음. 이제 카메라 진입 시 종류별 디폴트로 자동 리셋.

✨ 카메라 자유 비율 지원

카메라 모드에서도 selMediaRatio 드롭다운(1:1 / 16:9 / 9:16 / 4:5 / 자유) 사용 가능. 단 "원본 비율 맞춤 ON"은 UI 보호 위해 무시.

🧹 모드 전환 잔류 인라인 정리

updateImageSettings 진입 시 항상 captureArea + target의 잔류 height, aspectRatio 비움 → 모드 전환 누수 차단.

📱 모바일 fit 정밀화 & 짤림 해결

슬라이더 min 0.3 → 0.05, step 0.05 → 0.01. fit safety 0.88 → 0.95. 하단 60px safe margin 차감. fullscreen-preview에 dvh 적용.
